Dialogue limit: keep total text <= 2,000 chars. Continuity: TTS uses `previous_text`/`next_text`; dialogue uses `previous_text`/`future_text` (<=100 chars each), "not supported by every model". `output_format` is a query param (default mp3_44100_128).
